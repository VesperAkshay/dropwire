First off, thank you for considering contributing to DropWire!

Please note that DropWire is currently developed under a **Closed Source Proprietary License**.

### 🛑 Pull Requests
At this time, we are **not** accepting external code contributions, feature branches, or direct pull requests to the repository. Any unsolicited pull requests containing source code modifications will be closed.

### 🐛 Bug Reports & Feature Requests
We highly encourage and appreciate community feedback! If you find a bug, vulnerability, or have a suggestion for a feature:
1. Open an Issue in the GitHub issue tracker.
2. Provide as much detail as possible, including OS version, network conditions, and terminal logs.
3. For security vulnerabilities, please do not open a public issue. Email the maintainer directly to disclose it responsibly.

Thank you for helping us improve DropWire!
